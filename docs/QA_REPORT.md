## 3. 미검증 / 잔여 위험
- **실제 하드웨어(ESP32·센서·릴레이) 연동 시험은 미실시.** 현장 설치 전 센서 보정과 릴레이 동작 확인 필요
- YOLO/LLM 판독 화면은 모델 미설치 환경이라 직접 실행 못 함(코드 검토만)
- `config.toml`이 XSRF 보호를 끄고 있음. 외부망 노출 시 켜는 것을 권장
- 앱과 `collector.py`를 동시에 실행하면 이중 제어가 발생함. 둘 중 하나만 쓰거나 `"ui_collector": false` 설정 필요
- 경보 기준(위험도 70/85점, 이탈 여유폭)은 매뉴얼 기반 추정치. 현장 데이터로 보정 권장
